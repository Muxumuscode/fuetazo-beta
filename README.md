# Fuetazo: La Brújula del Fucú — beta

*Made by **Dembo**, un equipo de **Trobo Studio**.*

A top-down action game about Leo, a motoconcho driver (a motorcycle-taxi driver) in a parody
Dominican Republic. A cursed compass, the *Brújula*, is turning his family and neighbours into the
monsters of their own fears, the *cucos*. Leo frees them with his grandfather's machete: stand firm
against the yellow attacks, dodge the red ones, and when a cuco gets dizzy, land the **fuetazo**.
Every brand, place and institution in the game is made up or a parody.

**This is a beta: the first chapter (the Zona Colonial), about 10–15 minutes.** Thanks for testing!

## English

### Which one do I download?
| You play on | Download | |
|---|---|---|
| Any computer or phone, quickly | nothing: **[play in the browser](https://muxumuscode.github.io/fuetazo-beta/)** | keyboard, gamepad or touch |
| Android phone, tablet or handheld (Thor, Odin, Retroid...) | `Fuetazo-<version>-android.apk` | touch controls or a controller |
| Windows | `Fuetazo-<version>-windows.zip` | keyboard or gamepad |
| Linux / Steam Deck / Legion Go (Linux) | `Fuetazo-<version>-linux.tar.gz` | |
| Retro handhelds with PortMaster (Knulli, ROCKNIX, muOS...) | `Fuetazo-<version>-portmaster.zip` | experimental |

### Android
1. Download **`Fuetazo-<version>-android.apk`** and open it.
2. Android will ask to allow installing from your browser ("unknown apps"): allow it, go back, and
   tap **Install**. Needs a 64-bit Android device.
3. Play with the on-screen controls or any controller.

### Windows (64-bit)
1. Download **`Fuetazo-<version>-windows.zip`** and unzip it anywhere.
2. Run **`Fuetazo.exe`**. Windows will say *"Windows protected your PC"* because the game isn't
   code-signed: click **More info → Run anyway**.
3. It opens fullscreen. **Opciones → Pantalla** switches to a window (720p / 900p / 1080p);
   **Alt+Enter** or **F11** toggles fullscreen.

### Linux (64-bit)
1. Download **`Fuetazo-<version>-linux.tar.gz`** and extract it anywhere.
2. Run **`Fuetazo.x86_64`**. If your desktop won't run it: right-click → Properties → allow it to run
   as a program (or `chmod +x Fuetazo.x86_64`).

### Steam Deck
1. Hold the power button → **Switch to Desktop**.
2. Download **`Fuetazo-<version>-linux.tar.gz`** from the release page.
3. In **Dolphin** (the file manager), right-click the file → **Extract → Extract archive here**, and
   move `Fuetazo.x86_64` somewhere it will stay (for example `Games/Fuetazo` in your home folder).
4. Open **Steam** → **Games → Add a Non-Steam Game to My Library…** → **Browse…** → pick
   `Fuetazo.x86_64` → **Add Selected Programs**.
5. Back in **Gaming Mode**, Fuetazo is in your Library under **Non-Steam**. No Proton needed.

### Retro handhelds (PortMaster) — experimental
For ARM64 Linux handhelds with PortMaster: Miyoo Flip, Anbernic RG35XX / RG40XX / RG353, TrimUI,
Powkiddy and others, on Knulli, ROCKNIX, muOS, ArkOS...
1. Download **`Fuetazo-<version>-portmaster.zip`** and unzip it.
2. Copy **`Fuetazo.sh`** and the **`fuetazo`** folder into your SD card's `ports` folder (Knulli:
   `roms/ports/`), refresh the game list, and start **Fuetazo** from Ports. Have Wi-Fi on the first
   time (PortMaster may download a component once).
3. If the buttons do nothing, open `Fuetazo.sh` and set `USE_KEYBOARD=1`. If it doesn't start, please
   report it with the file `fuetazo/log.txt`.

### Updates: automatic
- **Browser:** always the newest version.
- **Android, Windows, Linux, Steam Deck:** the game **updates itself**. On the title screen it
  downloads the new version in the background ("Bajando la versión nueva…"), then asks you to restart
  (on Android: close it and open it again). After an update, the title shows what's new.
- Now and then a version needs a full download (the title says **"¡Hay una versión nueva!"** →
  **Actualizar**): install it the same way as the first time.
- **Your save is always kept.**

### Language
The first time you open the game it asks for **Español** or **English**; change it any time in
**Opciones → Idioma / Language**. **La Libreta de Leo** (on the title screen and in the pause menu)
explains the Dominican words, the people and how to fight each cuco.

## Español

### ¿Cuál descargo?
| Juegas en | Descarga | |
|---|---|---|
| Cualquier computadora o teléfono, rapidito | nada: **[juega en el navegador](https://muxumuscode.github.io/fuetazo-beta/)** | teclado, control o táctil |
| Teléfono, tablet o consola Android (Thor, Odin, Retroid...) | `Fuetazo-<versión>-android.apk` | controles táctiles o un control |
| Windows | `Fuetazo-<versión>-windows.zip` | teclado o control |
| Linux / Steam Deck / Legion Go (Linux) | `Fuetazo-<versión>-linux.tar.gz` | |
| Consolas retro con PortMaster (Knulli, ROCKNIX, muOS...) | `Fuetazo-<versión>-portmaster.zip` | experimental |

### Android
1. Descarga **`Fuetazo-<versión>-android.apk`** y ábrelo.
2. Android te pedirá permitir instalar desde el navegador ("apps desconocidas"): permítelo, vuelve y
   toca **Instalar**. Necesita un Android de 64 bits.
3. Juega con los controles en pantalla o con cualquier control.

### Windows (64 bits)
1. Descarga **`Fuetazo-<versión>-windows.zip`** y descomprímelo donde quieras.
2. Abre **`Fuetazo.exe`**. Windows dirá *"Windows protegió su PC"* porque el juego no está firmado:
   **Más información → Ejecutar de todas formas**.
3. Abre en pantalla completa. **Opciones → Pantalla** lo pone en ventana (720p / 900p / 1080p);
   **Alt+Enter** o **F11** cambia entre las dos.

### Linux (64 bits)
1. Descarga **`Fuetazo-<versión>-linux.tar.gz`** y extráelo donde quieras.
2. Abre **`Fuetazo.x86_64`**. Si no te deja: clic derecho → Propiedades → permitir ejecutarlo como
   programa (o `chmod +x Fuetazo.x86_64`).

### Steam Deck
1. Deja apretado el botón de encendido → **Cambiar a escritorio**.
2. Descarga **`Fuetazo-<versión>-linux.tar.gz`** de la página de la versión.
3. En **Dolphin**, clic derecho al archivo → **Extraer → Extraer aquí**, y mueve `Fuetazo.x86_64` a
   un lugar fijo (por ejemplo `Games/Fuetazo` en tu carpeta personal).
4. Abre **Steam** → **Juegos → Añadir un juego que no es de Steam a mi biblioteca…** → **Examinar…**
   → elige `Fuetazo.x86_64` → **Añadir programas seleccionados**.
5. En el **Modo de juego**, Fuetazo sale en tu Biblioteca, en **No de Steam**. No hace falta Proton.

### Consolas retro (PortMaster) — experimental
Para consolas Linux ARM64 con PortMaster: Miyoo Flip, Anbernic RG35XX / RG40XX / RG353, TrimUI,
Powkiddy y otras, con Knulli, ROCKNIX, muOS, ArkOS...
1. Descarga **`Fuetazo-<versión>-portmaster.zip`** y descomprímelo.
2. Copia **`Fuetazo.sh`** y la carpeta **`fuetazo`** a la carpeta `ports` de tu tarjeta SD (Knulli:
   `roms/ports/`), actualiza la lista de juegos y abre **Fuetazo** desde Ports. Ten el Wi-Fi puesto
   la primera vez (PortMaster puede bajar un componente una vez).
3. Si los botones no hacen nada, abre `Fuetazo.sh` y pon `USE_KEYBOARD=1`. Si no abre, repórtalo con
   el archivo `fuetazo/log.txt`.

### Actualizaciones: automáticas
- **Navegador:** siempre la versión más nueva.
- **Android, Windows, Linux, Steam Deck:** el juego **se actualiza solo**. En la pantalla de inicio
  baja la versión nueva por detrás ("Bajando la versión nueva…") y te pide reiniciar (en Android:
  ciérralo y ábrelo otra vez). Después de actualizar, la pantalla de inicio te dice lo nuevo.
- De vez en cuando una versión necesita descargarse completa (la pantalla dice **"¡Hay una versión
  nueva!"** → **Actualizar**): se instala igual que la primera vez.
- **Tu partida nunca se pierde.**

### Idioma
La primera vez te pide **Español** o **English**; lo cambias cuando quieras en **Opciones → Idioma /
Language**. **La Libreta de Leo** (en la pantalla de inicio y en el menú de pausa) explica las
palabras dominicanas, la gente y cómo pelear contra cada cuco.
